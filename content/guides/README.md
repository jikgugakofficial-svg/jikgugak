# 질문별 답 페이지 (/guide/<파일 이름>)

- 파일 하나 = 페이지 하나. `content/guides/<영문-슬러그>.md`, 맨 앞에 머리말(--- ~ ---), 그 아래 마크다운 본문.
- `_`로 시작하는 파일과 `status: draft`는 사이트에 안 나와요. 빌드: `npm run build` → `dist/guide/<슬러그>.html`, 사이트맵·/guide 목록에 자동 추가.
- 머리말 키: title(검색 질문 그대로 + 기준 숫자 + (2026)), question(목록에 보일 질문), description(검색 결과 설명 80~120자), updated(2026.10.28), order(목록 순서), cta(/calculator · /calculator#cart · /search), status(live/draft), faq(JSON 한 줄: [{"q":"","a":"","source":"공식 주소"}]).
- 본문 지원: `##`·`###` 제목, 문단, `-`·`1.` 목록, `| 표 |`, `**굵게**`, `[글](주소)`, `` `코드` ``, `>` 인용.
- 숫자 토큰(빌드 때 이번 주 값으로 바뀜): `{fx}` 과세환율 숫자(예 1,330.52), `{fxLabel}` "과세환율 ○원/달러 (기간 관세청 고시)" 전체 문구, `{krw150}`·`{krw200}` 면세 한도 원화(예 199,578). 원화 한도는 직접 숫자로 쓰지 말고 토큰으로.
- 제휴 링크·상품 가격 넣지 않음(계산기 버튼만). 아마존 가격 금지. 법·규정 숫자는 공식 출처 링크.
