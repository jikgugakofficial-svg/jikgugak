- 용도: 직구각 `/guide/<영문-슬러그>` 검색 답 페이지 12개의 소재와 구조
- 조사 방법: 웹 검색으로 상위 글 제목·게시일·구조를 보고, 주요 글은 열어서 확인. 관세청·언론 원문으로 법 수치를 확인. 본문은 옮기지 않고 구조만 적음. 제휴 링크(link.coupang.com, s.click.aliexpress.com, tag=jikgugak-20)는 열지 않음. 쿠팡·네이버쇼핑·다나와는 긁지 않음.

## 한계 (꼭 읽기)

- **구글·네이버 자동완성과 연관검색어는 이 환경에서 볼 수 없어요.** 그래서 "자동완성에 나옴"이라는 근거는 쓰지 않았어요. 근거 칸에는 실제로 본 상위 글 제목, 언론 기사, 지식iN 1건, 관세청 공식 페이지만 적었어요.
- **검색량 숫자는 없어요.** 확인 방법은 6장.
- **저장소 `git pull`을 하지 못했어요.** 이 환경에 셸 도구가 없어서 로컬 사본 기준으로 읽었어요(docs/status.md 10/28 09:50, 5주 계획 10/26).

## 0. 요약 5줄

1. 질문 12개는 계산·판정으로 바로 이어지고, 상위 결과가 계산기가 없거나 오래된 질문(2019년 원글을 갱신한 글, 2024년 가격 비교 기사) 위주로 골랐어요. 1·2·3·11번이 광군제 직전 블록이에요.
2. 가장 큰 기회는 합산과세입니다. 같은 판매자·같은 날 구매, 한 운송장 합산, 분할 주문 질문에 대해 글마다 설명이 달라요. 많은 글이 "한 운송장으로 들어오면 합쳐진다"는 조건을 빠뜨려요. 장바구니 계산기와 바로 이어져요.
3. 먼저 확인할 것은 과세가격에 국제 배송비가 들어가는지입니다. 사이트와 블로그는 "배송비 포함 전체 과세"라고 하는데, 2026-10-11 매일신문 기사는 "국제운송료는 뺀다"고 써요. 관세청 원문 확인 전에는 이 숫자로 페이지를 발행하지 않아요.
4. 검색 수요는 확인하지 못했어요. 지식iN 질문은 1건만 확인했어요. 자동완성과 검색량은 운영자·매니저가 브라우저로 확인해야 해요(6장).
5. 저장소 `git pull`은 하지 못했어요(셸 도구 없음). 로컬 사본 기준이에요.

## 2. 공통 페이지 구조 제안

- **제목 패턴:** "{검색 질문 그대로}? {핵심 기준 숫자 한 개} (2026)". 예: "알리 관세 얼마 나와요? 150달러·200달러 기준 계산 (2026)". 검색어를 앞에 둡니다.
- **첫 문단(2~3문장):** 답을 먼저 씁니다. 면세 기준 금액 1~2개와 원화값(이번 주 과세환율 기준, 적용 기간 표기)을 쓰고, "정확한 세액은 계산기에서"를 한 문장으로 붙입니다.
- **본문 순서:** ① 답 요약 표 ② 기준이 왜 그런지(기준 2개) ③ 계산 예시 1개(우리 계산 로직, 날짜 표기) ④ 계산기 버튼(/calculator 또는 /calculator#cart) ⑤ 주의 3개 ⑥ FAQ 3개.
- **FAQ 3개:** 질문 1개마다 공식 출처 링크 1개를 붙입니다(관세청 FAQ 등). FAQPage 구조화 데이터와 같이 씁니다(seo-strategist 담당).
- **숫자 표기:** 금액은 모두 원 단위로 쓰고, 달러 기준은 괄호로 원화를 붙입니다. 과세환율은 주간 값과 기준 기간을 같이 씁니다. 판정 단어가 들어간 문장은 빌드 토큰(`{total}`, `{be}`, `{beKrw}`)을 씁니다(CLAUDE.md 규칙).
- **제휴 링크:** 이 페이지들에는 제휴 링크를 넣지 않습니다. 계산기 버튼만 둡니다.
- **결론 표현:** "예상 세액", "관세청 고지가 최종"을 씁니다. 세율은 품목별로 다르다고 밝힙니다.

## 4. 쓰면 안 되는 것

- **"나눠 주문하면 무조건 면세", "같은 판매자는 항상 합산"** 같은 단정. 위 3장 6·7·8번이 확인되기 전에는 쓰지 않아요.
- **2019년 원글 기준 공식과 숫자.** 과세운임 위치가 맞지 않는 jab-guyver 공식도 가져오지 않아요.
- **가정 환율(1,300원·1,400원)을 실제 값처럼.** 사이트의 주간 과세환율만 써요.
- **"관세가 정확히 얼마"** 같은 단정. "예상 세액"으로 쓰고 관세청 고지가 최종이라고 밝혀요.
- **"목록통관이면 세금 없음"** 단정. 관세청 FAQ 463은 배제 품목이 섞여 들어오면 화물 전체가 목록통관에서 빠진다고 적어요.
- **아마존 가격과 특정 쇼핑몰 가격** 본문·예시에 넣기(CLAUDE.md 절대 규칙).
- **6병 = 영양제 전체 면세**로 쓰기. 6병은 개수 요건이고, 150달러 기준은 물품가격과 운송료 합계예요.
- **부가세 환급 단정.** 관세만 확인됐어요.
- **전파인증 "해외직구는 다 가능" / "다 불가능"** 같은 단정.
- **할인율 중심 문구.** 최종가 중심으로 씁니다(playbook 원칙).
- **경쟁 글 문장·소제목 순서 복사.** 구조(질문 유형·기준 종류)만 참고해요.
- **쿠팡·네이버쇼핑·다나와 긁기, 제휴 링크 열기.** 이번 조사에서는 하지 않았어요.

## 5. 예비 질문 (12개 밖)

- **개인통관고유부호 갱신(2026):** 질문 수요는 많아 보여요. 다만 근거가 언론 기사 중심이라 관세청 공지 확인 뒤에 쓰기 좋아요(3장 11번).
- **전자제품 직구 전파인증:** 질문은 많지만 직구각 판정(가격 비교)과 연결이 약해요. 면세 기준 얘기가 섞여 있어요(3장 12번).
- **알리 vs 쿠팡 가격 비교:** 상위 결과는 2024년 5월 가격 비교 기사 제목이 중심이고(예: asiae "알리, 최저가 아니네…쿠팡보다 45% 비싼 상품도", https://view.asiae.co.kr/article/2024050609415447524), 관세 포함 판정은 보이지 않음. 이미 N2 블로그 글과 `/deals/1111`이 맡아서 페이지는 우선순위가 낮아요.
- **알리 국내발송(국내 창고 발송) 관세:** 검색 결과가 대부분 무관해서 근거 자료를 찾지 못했어요. 근거 확보 전에는 소재로 쓰지 않아요.

## 6. 검색 수요 확인 방법 (운영자·매니저가 브라우저로)

이 조사에서는 검색량과 자동완성을 확인하지 못했어요. 아래는 확인하는 방법이에요.

- **네이버·구글 자동완성:** 검색창에 질문 앞부분을 입력해 목록을 캡처합니다. 로그인이 필요 없어요. 매니저가 브라우저로 하면 돼요.
- **구글 "관련 질문(People also ask)":** 시크릿 창에서 질문을 검색해 확인합니다.
- **구글 트렌드(공개):** 광군제·블프 시즌의 상대 관심도를 비교합니다. 절대 검색량은 나오지 않아요.
- **네이버 검색광고 키워드도구(월간 검색량):** 광고 계정 로그인이 필요해서 운영자가 확인해야 해요. 로그인은 운영자 몫입니다.
- **서치 콘솔(운영자 로그인):** 노출이 생기면 실제 검색어를 볼 수 있어요. 11/30 평가 때 같이 봐요.
