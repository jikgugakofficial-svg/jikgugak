확인 방법: 쿠팡·알리·아이허브·아마존 일반 상품 주소만 브라우저로 열어 확인(제휴 링크·스크래핑 서비스 미사용). 2026-10-23 11시경 확인. 쿠팡은 와우 쿠폰가가 아닌 상품 페이지 표시 판매가 기준. 아마존 가격은 기록하지 않았고 한국 배송 가능 여부만 확인. `data/products.json`은 수정하지 않았고 초안은 `content/_research/2026-10-23-new-products.json`에 있어요. 복사본에서 `npm test`·`npm run build` 통과 확인(기존 audit의 제휴 링크 누락 경고는 기존 상품 포함 원래 있던 것이고, 새 4개는 domesticUrl이 비어 있다는 경고만 나와요).

초안에서 정한 값과 근거
- 레고 10313 쿠팡 가격은 정가 대비 32% 할인 표시고 재고가 2개라 오래 못 갈 수 있어요. 품절되면 다음 최저가는 ₩78,400.
- 크레아틴 category는 `food`(기존 옵티멈 웨이 프로틴과 같게). `supplement`로 바꿔도 관세율·목록통관 배제·$150 한도가 같아 판정은 변하지 않아요.
- 크레아틴 쿠팡 가격은 지금 보이는 할인가(₩37,590)로 넣었어요. 할인이 끝나면(10/24 아침 전후) 가격 점검 때 ₩46,990으로 바꾸고 summary의 판정 문장을 다시 써야 해요.
- 4개 모두 `domesticUrl`(쿠팡 제휴 링크)·`image`는 비워 뒀어요. 아마존·아이허브 `buyUrl`은 기존 항목처럼 일반 주소를 넣었고(아마존은 빌드가 tag를 붙임, 아이허브는 제휴 승인 대기 중).

## 3. 매니저가 할 일

1. 쿠팡 파트너스 제휴 링크 생성(일반 주소 4개, JSON `domesticUrl`에 넣기)
   - 레고 10313: https://www.coupang.com/vp/products/7063125250
   - 레고 10281: https://www.coupang.com/vp/products/5998040219
   - 삼성 T7 Shield 1TB 블랙: https://www.coupang.com/vp/products/6888265108
   - 옵티멈 크레아틴 600g: https://www.coupang.com/vp/products/8203741079
2. 상품 이미지: 쿠팡 파트너스가 제공하는 이미지로 `image` 4개 채우기(제가 임의로 쿠팡 CDN 주소를 넣지 않았어요).
3. 아마존 한국 배송 재확인(제 확인은 10.23 11시, 로그인된 브라우저의 배송지 "Republic of Korea" 기준)
   - 10313: 직판 없음, 제3자 FBA 판매자만. 판매자가 바뀌거나 사라질 수 있어요.
   - 10281: 직판 없음. `unavailable`로 넣을지(블프 전 재입고 대비 페이지 선점) 뺄지 결정해 주세요. 뺀다면 JSON에서 두 번째 항목만 지우면 돼요.
   - T7 Shield: 재고·무료배송 확인됨. 다만 상품 페이지에 "Import Charges & FREE Shipping to Republic of Korea"로 수입 제세가 선결제로 표시돼요. 결제 단계 총액이 `손익분기 $227`(관세 0%+부가세 10%) 계산과 맞는지 직접 확인하고, 다르면 risks 문구를 고쳐 주세요. 다른 기존 아마존 상품에도 같은 표시가 있는지 한 번 보면 좋아요.
4. 아이허브 크레아틴 원화가 확인: 이 브라우저의 아이허브가 로그인된 채 US/USD 설정이라 kr.iherb.com이 www.iherb.com(달러)로 넘어가서 원화가를 못 봤어요. `priceKrw` ₩38,900은 $27.99를 기존 아이허브 항목의 원화/달러 비율(약 1,355~1,427)로 환산한 임시값이에요. 어느 값이어도(₩37,100~₩40,000) 판정은 "국내가 나음"(쿠팡 할인가 기준)이지만 숫자는 실제 원화가로 교체해야 해요. 계정 설정은 건드리지 않았어요.
5. 쿠팡 크레아틴 한정 할인 종료(약 10/24 07시) 뒤 가격 재확인, 레고 10313 재고 2개 재확인.
6. 데이터에 넣은 뒤 `npm test && npm run build`, `node scripts/audit.mjs`.

## 4. 이전 조사 문서와 달라진 점

- 크레아틴: 10.22 조사의 쿠팡 주소(8390833140)는 실제로 300g 상품이었어요. 600g은 8203741079로 교체했어요.
- 레고 10313: 쿠팡 상품이 로켓배송·재고 있음으로 확인돼 후보 문서의 "확인 필요"가 해소됐어요.
- BrickEconomy의 2026년 말 단종 예상은 이번에 다시 확인하지 못해 JSON 문구에 넣지 않았어요.

## 5. 작업 중 지킨 규칙 메모

- 제휴 링크(link.coupang.com, s.click.aliexpress.com, tag= 붙은 아마존 주소)는 열지 않았어요. 알리 상품 페이지 위쪽에 이 브라우저의 SiteStripe(제휴 도구 막대)가 떠 있었지만 누르지 않았어요.
- 이 브라우저는 쿠팡(와우 회원), 아마존(미로그인, 배송지 한국), 아이허브(jikgugak.official 계정, US/USD), 알리에 운영자 세션으로 접속돼 있었어요. 읽기만 했고 장바구니·구매·설정 변경은 하지 않았어요. 아마존 offer 목록 열기와 알리 색상 선택은 가격 확인용 화면 조작이에요.
- 아마존 페이지에서 가격이 화면에 보였지만 어디에도 적지 않았어요.
