## 3. 초안 JSON에서 정한 값
- 형식: 기존 아이허브 상품과 같음(`category: supplement`, `shipKrw` 6,000 또는 0, `priceKrw`, `domesticKrw`, `domesticSource`, `risks`, `summary` 3줄, `domesticCheckUrl`, `overseasCheckUrl`). `domesticUrl`·`image`는 비워 뒀고 `buyUrl`은 아이허브 일반 주소예요(제휴 승인 대기 중이라 `affiliatePending`에 iherb가 있어요).
- `domesticCheckUrl`에는 어떤 옵션(정수·수량)인지 고정되도록 `itemId`·`vendorItemId`가 붙은 쿠팡 일반 주소를 넣었어요(기존 락토비프 항목과 같은 방식). 제휴 링크가 아니에요.
- summary의 가격 차이는 `{diff}`·`{pct}` 토큰으로 썼어요. 모두 국내가 나음이라 손익분기(`{be}`)는 해당 없음(어떤 아이허브 가격이어도 기준을 못 맞춰요). 판정 단어가 든 문장은 가격이 바뀌면 price-checker가 다시 써야 해요.
- 복사본(스크래치 샌드박스)에 28개를 붙여 `npm test && npm run build`와 `node scripts/audit.mjs`를 돌렸고 통과했어요. audit 경고는 28개 모두 'domesticUrl 없음'과 '아이허브 링크가 제휴 링크 아님'(제휴 승인 대기)뿐이에요. 실제 `data/`는 그대로예요.

## 4. 매니저가 할 일
1. 어떤 것을 올릴지 결정(5장 추천 우선순위 참고). 올리는 상품만 쿠팡 파트너스 제휴 링크 생성 → `domesticUrl`, 쿠팡 파트너스 이미지 → `image`. 일반 상품 주소는 표 1장의 쿠팡 주소 열(= JSON `domesticCheckUrl`).
2. '확인 필요' 표시한 3개는 올리기 전에 눈으로 한 번 더 확인: 루테인(루테맥스 2020 표기), 사카로미세스 보울라디(지연방출 표기), 나우 울트라 오메가3(젤라틴 외피). 판정이 크게 벌어져 있어(국내가 나음, 아이허브가 ₩12,767~₩22,537 비쌈) 같은 제품이 아니어도 결론은 같을 가능성이 높지만, '같은 제품끼리' 원칙은 지켜야 해요.
3. 아이허브 가격은 프로모 코드(FESTA25, OCT26DAILY)가 걸린 표시가라 코드가 끝나면 올라가요. 쿠팡이 이미 더 싸서 판정은 안 뒤집히지만 숫자는 가격 점검 때 바뀌어요.
4. 비회원 배송비: 쿠팡 로켓직구의 무료배송 표시는 와우 회원 기준(`무조건 무료배송 (기간한정)`)이에요. 비회원 배송비는 확인하지 못했어요. 사이트 문구에 '무료배송'을 단정해서 쓸지 매니저가 결정해 주세요(JSON `domesticSource`에는 '와우 회원 표시 기준'이라고 적어 뒀어요).

## 6. 관찰과 다음 방향 제안
- 이번 28개는 모두 쿠팡 로켓직구(쿠팡이 직접 수입) 상품이에요. 로켓직구는 아이허브 소비자가보다 낮은 단가에 들여와서 이 구간에서는 사실상 직구각이 나오지 않아요. 기존 등록분(오메가3·마그네슘·D3K2·락토비프·웨이 프로틴)에서 직구각/애매가 나온 것도 쿠팡 쪽이 로켓직구가 아닌 국내 판매자 상품일 때였어요.
- 그래서 직구각 판정이 나올 후보는 '쿠팡에 아이허브 브랜드가 있지만 로켓직구가 아닌 판매자(해외배송·병행수입) 가격이 비싼 상품'일 가능성이 커요. 이번에 훑으며 본 예: 캘리포니아골드뉴트리션 오메가800(판매자 더로이, ₩31,660 2팩 기준, 배송비 ₩9,900 별도), 락토비프 300억 60정(판매자 슈드비직구, ₩73,100, 11/6 도착), 닥터스베스트 마그네슘 240정(판매자 티오티셀러 ₩39,300+배송비 ₩5,900), 라이프익스텐션 아터리얼 프로텍트 30캡슐(판매자 IHERB LLC ₩42,260). 다만 이런 상품은 판매자가 자주 바뀌고 배송비 조건이 달라서 '국내가' 기준이 불안정하고, 키크론 때처럼 사실상 해외 배송인 경우가 많아요. 다음 조사에서 이런 상품을 별도 기준(판매자 고정·도착일 확인)으로 뽑을지 운영자 판단이 필요해요.
