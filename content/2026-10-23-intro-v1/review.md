## 고친 것
1. 2장 제목 "검색 한 번에 / 최종가와 판정" → "국내가 옆에 / 해외 최종가". 검색은 알리 실시간 가격만 나오고 국내가를 넣어야 판정이 나와서, "검색 한 번에 판정"은 실제 기능보다 크게 말한 것. 2장 설명도 "관세·부가세·배송비까지 더해서 / 나란히 놓고 판정해요"로.
2. 캡션 둘째 문단 "살 때 해외직구가 더 싼지 확인하는 습관이 있으면 좋아요. 그런데 해외 가격만 보면 안 돼요." → "같은 물건이 해외에서 더 쌀 때가 있어요. 다만 해외 가격표만 보면 안 돼요." (어색한 문장)
3. 5장 설명 줄바꿈: "(화면은 예시)"만 다음 줄로 떨어지던 것 → "가격을 넣으면 판정과 / 면세 한도 신호등이 나와요(화면은 예시)".
- 다시 렌더 후 9장 전부 열어 확인. 잘림·겹침·오타 없음.

## 게시 전 매니저 확인 (CLAUDE.md 실물 확인)
- 유그린 7in1 허브: 쿠팡 CM512 ₩59,900(일반 주소), 알리 가격·배송비. 빌드값과 달라지면 2장 캡처 다시 찍기.
- 레고 10280: 아마존 한국 배송 가능 여부(가격은 기록 안 함), 손익분기 $43 그대로인지.
- 3장 알리 검색 캡처의 가격(₩29,449 등)은 실시간 검색 화면이라 게시 시점엔 다를 수 있음. 문구가 가격을 말하지 않아 막지는 않음.
