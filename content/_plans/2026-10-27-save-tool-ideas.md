# 저장형 '도구' 콘텐츠 아이디어 2개 (2026-10-27, 팀장 메모)

참고 게시물(henry_upnomad, 7장, 좋아요 235·댓글 283·공유 50)은 "복사해서 바로 쓰는 도구"를 주니까 저장·공유가 많았어요. 직구각 버전은 **결제 직전에 다시 꺼내 보는 것**이에요. 10/31 이후 카드뉴스는 쉬니까 릴스(화면 녹화 + 자막) + 스레드로 먼저 만들고, 마지막 화면은 profile-cta, 캡션은 💡·📌 표준(`docs/marketing/playbook.md`). 훅은 `docs/marketing/hook-rules.md` 절차(10개 표 → 팀장 1개).

## 1. 장바구니 합산 계산기 4단계 (광군제 11/11 전 11/6~11/9, 블프 버전 11/20쯤)
- **도구:** `/calculator#cart`(10/27 새로 생김). 쇼핑몰별로 상자가 나뉘어 면세 한도·세금·배송비를 따로 계산하고, 넘으면 "○○ 1개만 빼면 면세예요. 세금 ○원이 사라져요"를 보여 줘요.
- **구성(장면 5~6개):** 훅 → ① 쇼핑몰 고르기 → ② 알리 상품 주소 붙여넣기(이름·가격 자동) → ③ 면세 신호등 → ④ "1개만 빼면 면세" 안내 → 요약 → profile-cta.
- **방식 후보:** 흔한 실수("하나씩 따로 계산하면 놓치는 것"), 숫자 대비(빼기 전·후 세금), 질문("장바구니, 면세 한도 안에 들어가요?").
- **숫자:** 예시 장바구니는 사이트 등록 상품(알리 일반가)으로 만들고, 세금·한도 숫자는 계산기 화면 그대로 + 그날 환율(publish.json `fxCheck`).
- **주의:** "나눠 주문하면 면세"는 쓰지 않아요(같은 날 들어오면 합산과세, 사이트에도 안 넣은 안내). 신규 회원가·쿠폰가로 예시 만들지 않기. 화면 속 신호등의 노란 불은 기능 표시라 그대로 둬요(브랜드 색으로 쓰지는 않음).
- **📌 예:** "📌 장바구니 결제 전에 꺼내 보게 저장해 두세요"

## 2. 결제 직전 30초 체크리스트, 저장용 한 장 (S2-03 10/29 게시 반응 보고 결정)
- **도구:** S2-03(`content/2026-10-27-s2-03-checkout-30s`)의 5가지(현지 통화 결제, 면세 한도, 합산과세, 배송비 기준, 통관부호)를 **화면 하나에 다 들어가는 체크표**로 줄여, 릴스 마지막 3초에 멈춰 두고 캡처하게 해요.
- **언제:** 11/1 세트 2 회고에서 S2-03 저장 수가 다른 글보다 높으면 블프판(아마존 미국 특송 200달러 기준)으로 11/24~11/26 게시.
- **방식 후보:** 질문("결제 버튼 누르기 전, 5개 다 봤어요?"), 흔한 실수(원화 결제를 누르면 수수료를 더 내요), 반전.
- **숫자:** 한도 원화는 게시 주의 과세환율로 다시 계산. 아마존 배송비 기준 금액은 게시 전 매니저가 아마존 화면에서 다시 확인(가격 숫자는 쓰지 않음).
- **📌 예:** "📌 블프 결제 전에 꺼내 보게 저장해 두세요"

## 3. 쇼핑몰별 번호 연재 "01 알리 ~ 04 쿠팡 로켓직구" (블프 준비 11/13~11/20, 네이버 N6~N10 소제목 틀로도)
참고: every._ai 번호형 10장(같은 틀 반복 + 진행 표시, `playbook.md` 맨 아래). 저장 이유 = "쇼핑몰마다 다른 기준을 한 번에".
- **구성:** 훅 → `01 알리`(그 외 국가 150달러, 신규 회원가 말고 일반가로 계산) → `02 아마존`(미국 특송 200달러, 가격 대신 "얼마 이하면 직구각"인 손익분기) → `03 아이허브`(영양제는 어디서든 150달러·6병, 4만 원 미만 배송비) → `04 쿠팡 로켓직구`(국내 결제지만 해외 배송, 국내 최저가 칸에 넣을지 확인) → 요약 → profile-cta.

- **숫자:** 한도 원화는 게시 주의 과세환율로 다시 계산, 아이허브 배송비는 게시 전 매니저가 kr.iherb.com에서 다시 확인. 아마존은 가격 숫자 없음.
- **CTA 시험:** 이 글은 📌 대신 "사고 싶은 직구템 이름을 댓글로 남겨 주세요" (운영자 직접 답글, `playbook.md` 댓글 판정 요청).
