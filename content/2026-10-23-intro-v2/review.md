## 고친 것 (핵심: 계산기 설명이 실제와 달랐음)
계산기는 상품가·국제 배송비·국내 최저가를 넣어야 판정이 나오는데, "상품 가격만 넣으면 최종가와 판정"이라고 써 있었어요.
1. 표지 부제 "상품 가격만 넣으면 / 최종가와 판정이 나와요" → "상품가·배송비를 넣으면 / 관세 포함 최종가가 나와요"
2. 2장 제목 "가격만 넣으면 / 최종가까지" → "숫자 몇 개면 / 최종가까지", 설명 → "상품가·배송비에 관세·부가세를 더해요 / 국내가도 넣으면 판정까지(화면은 예시)"
3. 정리 장 "상품 가격만 넣으면 계산 끝" → "상품가·배송비·국내가만 입력"
4. 캡션 첫 줄 "가입 0번, 설치 0번. 가격만 넣으면 관세까지 계산해요" → "가입 0번, 설치 0번. 직구 관세를 바로 계산해요", 본문 "상품 가격만 넣으면 돼요" → "상품가와 배송비, 국내 최저가만 넣으면 돼요"
5. 스레드 1 첫 문장 "상품 가격만 넣으면" → "상품가와 배송비만 넣으면"
6. alt 문장 맞춤. 3장 설명 줄바꿈("비교해요"만 떨어지던 것) 정리.
- 다시 렌더 후 10장 전부 열어 확인. 잘림·겹침 없음.
