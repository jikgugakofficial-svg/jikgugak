# 직구각 법정 (큰 결정 전에 판결부터)

참고: lazy_owen "클로드 법정"(10/12). 결정 하나를 검사·변호인이 다투고, 입장이 다른 배심원 12명이 읽고 표결해요. 칭찬 대신 **무엇이 바뀌면 표가 뒤집히는지**가 나와요.

## 언제 여나
- 되돌리기 어렵거나 돈·시간이 크게 드는 결정: 새 기능·새 페이지(블프 페이지 등), 새 직원, 새 채널, 11/30 평가 뒤 방향, 홍보 형식을 바꿀 때.
- 운영자가 "법정 열어 줘"라고 할 때.
- 작은 일(문구 한 줄, 가격 고치기)엔 열지 않아요.

## 넣는 것 (숫자로, 모르면 "모름")
```
안건: [한 문장, 예: 11/12에 블프 시즌 페이지를 연다]
지금 숫자: [방문자·클릭·팔로워·남은 날짜·드는 시간 등, 출처와 날짜]
하면 드는 것: [운영자 시간 / 매니저 작업량 / 돈]
안 하면 하는 것: [대안]
```
숫자 없이 "할까?"만 넣으면 배심원도 감으로 답해요. status.md·`content/_insights/latest.json`·`/admin` 숫자를 먼저 붙여요.

## 진행 (매니저가 한 번에)
1. **검사:** 이 결정이 틀릴 이유 3개(숫자 근거).
2. **변호인:** 맞을 이유 3개(숫자 근거).
3. **배심원 12명**이 양쪽을 다 읽고 각자 입장에서 유죄(하지 마)/무죄(해) + 한 줄 이유.
4. **판결:** 표 수, 결론, 그리고 **표를 뒤집으려면 무엇이 바뀌어야 하는지** 2~3개.

## 배심원 12명 (직구각용, 고정)
| # | 배심원 | 보는 것 |
| --- | --- | --- |
| 1 | 직구 처음인 대학생 | 이해되나, 겁나지 않나 |
| 2 | 아이허브 정기 구매 부모 | 시간 아끼나, 영양제 한도 |
| 3 | 알리 광군제 장바구니 직장인 | 결제 직전에 쓸 수 있나 |
| 4 | 쿠팡 로켓 충성 고객 | 굳이 직구할 이유 |
| 5 | 테크 덕후(같은 모델 집착) | 비교가 정확한가 |
| 6 | 네이버·구글 검색 | 찾을 만한 페이지가 생기나 |
| 7 | 인스타 알고리즘 | 저장·공유·팔로우가 생기나 |
| 8 | 제휴 약관 담당 | 규칙 위반 위험 (`docs/affiliate-terms.md`) |
| 9 | 회계사 | 11/30까지 첫 정산에 가까워지나 |
| 10 | 경쟁 서비스 운영자 | 쉽게 따라 할 수 있나 |
| 11 | 통계 담당 | 결론 낼 만큼 숫자가 있나 |
| 12 | 운영자의 하루 | 운영자 손이 얼마나 드나 |

## 지킬 것
- 배심원은 **흉내 낸 입장**이에요. 판결문을 후기·고객 의견처럼 홍보에 쓰지 않아요.
- 판결은 참고예요. 결정은 운영자가 해요(되돌리기 어려운 일은 늘 운영자 확인).
- 결과는 `content/_plans/YYYY-MM-DD-court-<주제>.md`에 남기고, 결정이 나면 status.md 1장(확정된 방향)에 한 줄.
