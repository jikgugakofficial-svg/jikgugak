# 직구각 훅 규칙 (A4 1쪽, 카드 표지·릴스 첫 화면·캡션 첫 줄·스레드 첫 문장을 쓸 때마다 펴 놓기)

> 2026-10-27 참고 카드뉴스(henry_upnomad "훅 규칙으로 40만", 7장, 좋아요 235·댓글 283·공유 50) 분석을 직구각 규칙에 맞게 옮겼어요. 문장은 가져오지 않고 방식만 가져왔어요. 블로그 제목·첫 문단은 검색용이라 지금처럼 결론부터 써요.

## 1. 말투 (voice.md 요약)
- 친근한 존댓말(~해요), 짧은 문장, 한 문장에 숫자 하나. 숫자가 형용사보다 먼저.
- 금액은 모두 "원"(달러 한도는 "200달러(약 26만 6천 원)"처럼 원화를 크게). 숫자엔 기준 날짜가 따라가요.
- 국내가 나으면 국내가 낫다고 말해요. 체험담("제가 사 보니")은 쓰지 않아요.

## 2. 훅 규칙 6개
1. **답은 숨기고 궁금증만 남겨요.** 판정 단어(직구각·국내가 나음)와 이유는 표지에 쓰지 않아요. 판정은 2~3장(릴스는 7초 안)에서 바로 주고, 끝까지 보게 하는 건 "언제 직구각이 되나(손익분기)"를 뒤에 두는 걸로 해요.
2. **숨겨도 거짓은 안 돼요.** 답을 본 뒤에도 훅이 사실이어야 해요. 없는 반전·과장은 낚시예요.
3. **화면 글자는 한 줄 10어절 이하.** 기존 글자 수 제한이 더 엄해요: 표지 한 줄 6~12자·두 줄까지, 릴스 자막 한 장면 12자.
4. **화면 글자 = 첫마디.** 표지(릴스 첫 화면)에 쓴 말과 캡션 첫 줄(스레드 첫 문장)이 같은 말, 같은 숫자예요. 따로 놀면 안 돼요.
5. **숫자는 구체적으로 하나.** "많이 싸요" 대신 "26,588원". 숫자는 빌드 결과·상품 페이지에 있는 것만, 기준 날짜는 부제나 캡션에.
6. **아마존은 가격 숫자 대신 손익분기만.** "아마존가 ○○원 이하면" 형태(원화 환산)만 써요.

## 3. 방식 5가지 (훅 10개는 이 다섯 가지를 고르게 섞어요)
| 방식 | 직구각 틀 | 숨기는 것 |
| --- | --- | --- |
| 숫자 대비 | "{국내가} vs {해외 체감가}, 다 더해 봤어요" | 어느 쪽이 이겼는지 |
| 질문 | 결제 직전 순간의 질문 "이 차이로 1~2주 기다려요?" | 기다릴 만한지 |
| 흔한 실수 | "{흔한 행동} 하면 {숫자}원이 붙어요" | 어떤 행동인지, 피하는 법 |
| 반전 | 통념 "직구가 싸죠"를 뒤집는 숫자 하나 | 왜 뒤집혔는지 |
| 직구각 데이터 사례 | "직구각이 판정한 {N}개 중 {k}개는..." (빌드로 센 실제 숫자) | 어떤 상품인지 |

참고 게시물의 '내 경험' 방식은 쓰지 않아요(체험담 지어내기 금지). 그 자리를 직구각 데이터 사례가 맡아요.

## 4. 절대 안 쓰는 표현 10개
1. 역대급·미쳤다  2. 무조건  3. 인생템·가성비 끝판왕·필수템  4. 지금 안 사면 손해·놓치지 마세요
5. 관세 폭탄·세금 폭탄(겁주기)  6. 총정리·완벽 정리·이것만 알면 끝
7. 근거 없는 "최저가"·"최저가 보장"·"제일 싸요"(비교 대상과 기준 날짜 없이)
8. 아마존 가격 숫자  9. 예측("블프 땐 더 내려가요", "곧 올라요")  10. 체험담·후기("써 보니 좋아요", "제가 사 보니")

## 5. 좋은 훅 예시 3개 (숫자는 2026-10-27 빌드·상품 페이지 기준, 쓸 때 다시 빌드해서 확인)
| 방식 | 화면 글자 | 첫마디 | 근거 |
| --- | --- | --- | --- |
| 반전 | 이 오메가3, 아이허브면\n26,588원 더 내요 | 이 오메가3는 아이허브에서 사면 26,588원 더 내요(10.27 기준) | /p/iherb-sr-omega3-triple-180 (10.27 오전, 아이허브 74,508원 vs 쿠팡 로켓직구 47,920원). 쿠팡 로켓직구도 직구라서 "직구하면 더 내요"라고 쓰면 틀려요 |
| 흔한 실수 | 배송비 6,000원이\n판정을 바꿔요 | 아이허브 오메가3는 배송비 6,000원이 판정을 바꿔요 | /p/iherb-cgn-omega3-premium-100 (10.27 오전, 1개만 사면 8,638원 싸서 애매, 4만 원 넘게 함께 담으면 14,638원 싸서 직구각 기준을 넘어요) |
| 데이터 사례 | 판정 {N}개 중\n{k}개는 국내가 나았어요 | 직구각이 판정한 {N}개 중 {k}개는 국내가 나았어요({날짜} 기준) | 게시 당일 npm run build 출력으로 세요(아마존은 손익분기라 셈에서 빼요). 10/27 하루에도 오전 23개 중 16개 → 오후 19개로 바뀌었어요(알리 일반가 기준 변경). 대부분이 아이허브 영양제·보충제(10/27 오후 19개 중 14개)라 2장에서 꼭 밝혀요 |

## 6. 전/후 예시 (주제형 제목 → 궁금증형)
- ❌ "알리 관세 계산법" → ⭕ "장바구니에서 하나만 빼면\n세금이 0원" (실제 예시 장바구니 숫자가 2장에 있어야 써요. `/calculator#cart`의 "1개만 빼면 면세" 안내 화면)
- ❌ "블프 아마존 면세 한도 정리" → ⭕ "이 금액 넘기면\n배송비에도 세금 붙어요" (금액은 2장: 물품가 200달러(약 26만 6천 원), 그날 환율)
- 답(한도 금액, 뺄 상품)을 숨기면 넘겨 봐요. 대신 다음 장에서 바로 답해요.

## 7. 쓰는 순서
작가가 훅 10개를 표로(번호 | 화면 글자 | 첫마디 | 방식, 방식 5가지가 모두 한 번 이상) → 작가 추천 1개로 카드·릴스 제작 → 팀장이 검수 때 1개를 고르고 이유 한 줄을 review.md에(작가 추천과 다르면 팀장이 cards.json 고치고 다시 렌더).
