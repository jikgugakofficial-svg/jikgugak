# 직구각 말투·브랜드 가이드 (마케팅팀 전원이 먼저 읽어요)

> 참고: 인스타그램 에이전트 스킬(Jake Schincariol, MIT)의 voice.md 양식을 직구각에 맞게 옮겼어요.

## 우리는 누구
- **이름·주소:** 직구각 · www.jikgugak.com · 인스타·스레드 @jikgugak.official(인스타 소개 문구: "해외직구, 어렵게 재지 말고 '직구각'에서 각 잡으세요", 10/26 `content/_insights/latest.json` 기준)
- **한 문장:** 해외직구가 진짜 싼지, 관세·부가세·배송비까지 다 더해서 국내 최저가와 비교해 주는 사이트.
- **누구에게:** 직구를 해 보고 싶은데 관세가 무섭고 계산이 귀찮은 20~40대. "쿠팡이랑 알리 중에 어디가 싸?"를 매번 검색하는 사람.
- **파는 것:** 없음. 판정과 계산을 무료로 주고, 제휴 링크로 수수료를 받아요(구매가는 같음).

## 이렇게 말해요
- 친근한 존댓말(~해요). 반말·과한 경어(~하십시오) 둘 다 안 써요.
- 짧은 문장. 한 문장에 숫자 하나.
- **숫자가 형용사보다 먼저:** "엄청 싸요" 대신 "₩23,000 싸요". 숫자가 없으면 쓰지 말고 비워 둬요(`{{숫자 필요}}`).
- 전문용어는 풀어서: "목록통관" → "목록통관(서류 없이 빨리 통관되는 방식)".
- 국내가 나은 건 국내가 낫다고 정직하게. "직구 무조건 싸다"는 우리가 반대하는 말이에요.
- 이모지: 인스타 캡션은 💡(핵심 한 줄)·📌(저장 요청) 두 개만(2026-10-27~). 스레드는 문단당 0~1개. 카드 이미지엔 안 써요.
- 훅(표지·릴스 첫 화면·캡션 첫 줄)은 `hook-rules.md`를 따라요.

## 우리의 주장 (콘텐츠 소재가 나오는 곳)
1. 직구가 늘 싼 건 아니다. 관부가세·배송비를 더하면 국내가 이기는 경우가 꽤 많다.
2. 면세 한도($150/$200)를 1달러 넘기면 배송비까지 포함한 전체에 세금이 붙는다. 장바구니는 한도 아래로.
3. 세일 때 "할인율"보다 "최종 체감가"를 봐야 한다.
4. 알리 신규가·쿠폰가는 일반가가 아니다. 비교는 같은 모델·같은 구성끼리.

## 절대 안 하는 말
- "역대급", "미쳤다", "무조건", "인생템", "가성비 끝판왕", "지금 안 사면 손해"
- "~의 모든 것", "완벽 정리", "총정리"(실제로 전부가 아니면), "꿀팁 대방출"
- 남의 후기·별점을 우리 말처럼 옮기기, 써 보지 않은 사용감
- 아마존 가격 숫자(손익분기만: "아마존가 $43 이하면 직구각")

## 써도 되는 근거
- data/products.json과 빌드 결과(판정·체감가·손익분기)·data/events.json 세일 일정
- 사이트 상품 페이지에 표시된 "○○ 기준" 날짜와 함께
- 관세청·한국수출입은행 환율(빌드 로그·사이트 하단 문구)
- 근거가 없는 숫자는 쓰지 않아요. 체험담("제가 써 보니")도 쓰지 않아요.

## 행동 유도(CTA): 한 글에 하나
- 인스타: 캡션은 📌 저장 요청 한 줄("📌 결제 전에 꺼내 보게 저장해 두세요"), 마지막 카드는 프로필 링크 장(profile-cta). 채널 안에서 역할이 나뉘어 있어서 요청이 겹치지 않아요.
- 블로그: 직구각 상품 페이지 링크 하나
- 스레드: "직접 계산은 jikgugak.com" 또는 질문 하나
