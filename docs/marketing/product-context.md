# 직구각 제품 맥락 (마케팅팀·검색 담당이 일 시작 전에 읽는 한 장)

**문서 버전:** v2 (2026-10-28)
참고: Corey Haines `marketingskills`(52개 스킬 묶음)의 `product-marketing` 양식을 직구각에 맞게 옮겼어요. 이 문서가 있으면 직원마다 "직구각이 뭐냐"를 다시 설명하지 않아도 돼요. 말투는 `voice.md`, 훅은 `hook-rules.md`, 규칙은 `CLAUDE.md`가 원본이고 여기엔 겹쳐 쓰지 않아요.

## 1. 한 줄과 진열대
- **한 줄:** 해외직구 최종 가격(상품가 + 국제 배송비 + 관세·부가세)이 국내 최저가보다 정말 싼지 판정하는 무료 사이트.
- **사람들이 찾는 진열대(검색어):** "알리 관세", "직구 관세 계산", "알리 vs 쿠팡", "아이허브 쿠팡 가격 비교", "광군제/블프 직구". 우리는 "가격 비교 사이트"보다 **"관세까지 넣은 직구 판정"** 칸에 서요.
- **돈 버는 법:** 쿠팡 파트너스·알리·아마존 제휴 수수료(구매가 같음). 판정이 국내가 나음이면 국내 링크를 먼저 보여 줘요.

## 2. 누구의 어떤 순간
- **결제 직전의 직구 고민러:** 알리·아마존 장바구니를 채워 놓고 "관세 붙나? 쿠팡이 더 싸나?"를 검색하는 20~40대.
- **영양제 정기 구매자:** 아이허브 4만 원 무료배송·6병 한도를 맞추는 사람.
- **세일 시즌 사냥꾼:** 광군제(11/11)·블프(11/27)에 할인율만 보고 사려는 사람.
- **우리가 해 주는 일(JTBD):** ① 같은 제품끼리 최종가 한 번에 비교 ② 면세 한도 넘는지 바로 알기 ③ "이 가격 이하면 사도 된다"는 기준 받기.

## 3. 고통과 지금의 해결책
- 관세·부가세·배송비 계산이 귀찮고, 150달러·200달러 경계에서 틀리기 쉬워요(커뮤니티 질문 1위: 배송비 포함 여부·같은 날 합산).
- 알리 화면엔 신규 회원가·쿠폰가가 섞여 있어 진짜 가격을 모르겠어요.
- 쿠팡 로켓직구·국내 정발과 같은 모델인지 확인하기 어려워요.
- **지금 사람들이 쓰는 것:** 관세청 UNI-PASS 예상세액·배대지 계산기(세금만, 국내가 비교 없음), 다나와·에누리·네이버 가격비교(국내 위주), 뽐뿌·퀘이사존 해외 핫딜 게시판(사람이 계산, 글마다 기준 다름), 그냥 쿠팡에서 사기(귀찮음 회피).

## 4. 차별점 (증거와 함께만 말해요)
| 차별점 | 증거 |
| --- | --- |
| 관세·부가세·배송비까지 넣은 **최종가**로 비교 | 상품 페이지 '체감가 영수증' |
| **같은 제품끼리만** 비교(바코드·모델번호·옵션) | 상품 페이지 '같은 제품 확인' 줄 |
| 국내가 나으면 **국내가 나음**이라고 말함 | 등록 상품 중 국내가 나음 판정이 여럿(사이트 그대로) |
| 알리 링크 붙이고 **국내 최저가만 넣으면** 판정 | 홈·`/search`·`/deals/1111` 입력창 |
| 가입 없음, 무료 | 사이트 전체 |
- 쓰지 않는 주장: "최저가 보장", "3초 판정"(단독), "모든 상품".

## 5. 망설이는 이유와 답
| 망설임 | 답 |
| --- | --- |
| "제휴 사이트면 직구 쪽으로 몰아가겠지" | 국내가 나음 판정 사례를 먼저 보여 줘요(아이허브 오메가3 카드처럼). |
| "가격이 금방 바뀌잖아" | 페이지마다 기준 날짜, 쿠팡·알리 매시간 자동 확인, 지금 가격 넣어 다시 판정 가능. |
| "같은 모델 맞아?" | 같은 제품 확인 줄(바코드/모델). 붙여넣기 판정은 같은 모델 확인을 사용자에게 분명히 부탁. |
| "관세 계산 틀리면?" | 관세청 과세환율 사용, 최종 세액은 세관 고지를 따른다고 표시. |

## 6. 바꾸게 만드는 힘 (밀기·끌기·습관·불안)
- 밀기: 관세 고지서에 놀람, 알리 가격 혼란. 끌기: 한 화면에 최종가와 판정.
- 습관: "그냥 쿠팡"·"핫딜 글 보고 사기". 불안: 제휴 링크라 믿어도 되나.
- → 콘텐츠는 **불안을 먼저 풀고**(국내가 나음도 말함) 끌기를 보여 줘요.

## 7. 사람들의 말 (요지만, 원문 복사 금지)
- 문제를 말할 때: "딱 150달러면 관세 내요?", "배송비도 포함돼요?", "날짜 다르게 사면 합산돼요?", "알리 광군제 다들 뭐 사요?", "쿠팡이랑 알리 어디가 싸요?"
- 쓸 말: 최종가, 관세 포함, 같은 모델, 면세 한도, 국내가 나음, 이 가격 이하면.
- 피할 말: voice.md '절대 안 하는 말' 그대로.
