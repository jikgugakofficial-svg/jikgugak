# 직구각 마케팅 플레이북 (채널별 형식)

먼저 `product-context.md`(직구각이 누구에게 무엇을)와 `voice.md`(말투)를 읽고, 훅(표지·첫 화면·첫 줄)을 쓸 땐 `hook-rules.md`를 펴 놓아요. 검수는 `review-checklist.md`, 카드 규격은 `card-spec.md`, 영상은 `motion-reference.md`.
출처: 인스타그램 에이전트 스킬(Jake Schincariol, MIT)·marketingskills(Corey Haines)와 운영자가 보낸 참고 게시물들을 한국 채널과 직구각 규칙에 맞게 옮긴 것이에요. 가져오지 않기로 한 것은 `docs/status.md` 2장에 있어요.

## 1. 원칙
- **쓰는 건 팀이, 올리는 건 운영자가 승인.** 게시는 운영자 "게시해" 뒤 공식 API로만. 댓글·팔로우·DM 자동화는 하지 않아요(계정 정지 위험).
- **한 콘텐츠 = 한 판정.** 결론은 직구각/애매/국내가 나음 중 하나. 국내가 나으면 그대로 말해요(그게 신뢰예요).
- **기능 소개로 시작하지 않아요.** 직구하는 **순간**을 보여 줘요(광군제 장바구니 결제 직전, 블프 200달러 한도 앞). **누가 + 언제**를 짝지어 기획해요(영양제 사는 사람 → 아이허브 4만 원 맞출 때).
- **하나의 소재 → 여러 채널:** 블로그(검색 유입) · 릴스(도달) · 스레드(대화). 같은 숫자, 채널별 형식. 10/31 이후 카드뉴스는 쉬어요.
- **저장형 '도구' 콘텐츠를 섞어요.** 체크리스트·계산 순서처럼 결제 전에 다시 꺼내 볼 것이 저장·공유를 불러요(`content/_plans/2026-10-27-save-tool-ideas.md`).
- **금액은 모두 "원".** 달러 기준은 "200달러(약 26만 8천 원)"처럼 원화를 크게. 아마존은 가격 숫자 없이 손익분기만(결제 환율로 원화 환산 가능). 사이트 화면 캡처 속 ₩는 그대로.
- 결과물 폴더: `content/YYYY-MM-DD-주제/` → `brief.md`(팀장) · `blog.md` · `instagram.md` · `reel.md` · `threads.md` · `cards.json`+`cards/*.png` · `review.md`(팀장 검수) · `publish.json`(승인 뒤).

## 2. 광고 표시 (빠지면 안 됨)
- 블로그 맨 위: "이 글은 제휴 활동의 일환으로, 글 속 링크로 구매하면 직구각이 수수료를 받을 수 있어요(구매가는 같아요)."
- 쿠팡을 언급하며 링크를 걸면: "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."
- 인스타: 게시할 때 "유료 광고 포함" 표시, 캡션 **첫 줄**에 `#광고`, 카드 표지에 "광고 · 제휴 링크 포함". 직구각 자체 광고(상품 추천 없는 서비스 광고 영상)는 표시하지 않아요.
- 스레드: 첫 글 **맨 앞**에 `(광고)`(둘째 글은 끝에). `#광고`는 주제 태그로 잡혀 노출을 잃어요. 주제 태그는 publish.json `topicTag`.
- 본문 링크는 제휴 링크 대신 **직구각 페이지 주소**(`/p/슬러그`, `/deals/1111`, `/calculator`)만.

## 3. 네이버 블로그 (검색 유입의 주력, 주 2편)
- **제목:** 검색어를 앞에, 25~35자, 후보 3개. 예: "레고 꽃다발 직구 vs 쿠팡, 관세까지 계산해 보니".
- **첫 문단(3줄):** 결론 먼저. 판정 + 핵심 숫자 + 기준 날짜.
- **구성:** ① 결론 요약 표(국내가·해외 체감가·차이·판정) ② 왜 이런 결과인지(관세·면세 한도·배송비) ③ 언제 직구각이 되는지(손익분기·세일) ④ 주의할 점 3개 ⑤ 직구각 링크 하나.
- 1,500~2,500자, 소제목 4~6개(사람들이 묻는 말 그대로), 표 1~2개. 검색어는 제목·첫 문단·소제목 1곳에 자연스럽게.
- 이미지 자리는 `[이미지: 설명]`(제휴 프로그램 이미지 또는 직구각 카드만). 네이버 태그 10개 이내.
- 연재 틀(쇼핑몰별·단계별): 소제목을 `01. 알리` / 한도 한 줄 / 상자 "틀리기 쉬운 것 1개"처럼 같은 자리로 반복하면 끝까지 읽혀요.
- 게시는 운영자가 직접(네이버 글쓰기 API 없음): 매니저가 게시 키트(아티팩트 + 사진 zip)를 줘요.

## 4. 인스타 릴스 (10/31 이후 주력, 주 2개 안팎)
- 15~35초, 얼굴·목소리 없이 화면 글자 + 직구각 자작곡. 구조: 0~2초 훅 → 2~7초 이유 → 본문(한 박자 = 한 장면) → 마지막 3초 결과 + 요청 → 첫 단어로 되돌아오는 마무리.
- 화면 자막은 한 장면 12자 이내, 아래쪽(캡션 가리는 곳)엔 넣지 않기. 사용자가 할 일 한 칸만 주황 배경으로 강조("국내 최저가 [   ]원").
- **공정 4단계(사람·도구 나누기)**

| 단계 | AI 팀 | 운영자 | 남는 파일 |
| --- | --- | --- | --- |
| 1 참고 분석 | 매니저가 장면 사진으로 바꿔 장면표(`motion-reference.md` 6장) | 마음에 드는 릴스 링크 보내기 | `content/_research/` |
| 2 대본 | social-writer 훅 10개 표 + 대본, 팀장 1개 선택 | 없음 | `reel.md` |
| 3 화면 | 매니저가 `tools/tvc`로 굽기 | 미리보기 보고 "게시해" | `publish/reel.mp4` |
| 4 게시·댓글 | Actions 예약 게시 + 스토리 자동 공유, cs-responder 답글 초안 | 첫 1시간 안에 답글 | `publish-result.json` |

## 5. 인스타 카드뉴스 (10/31 이후 쉼, 다시 쓸 때 규격)
- 6~10장, 1080×1350. ① 표지(6~12자 훅 + 한 줄 약속, 썸네일에서도 읽히게) ② 문제 제기(두 번째 표지 역할) ③~N 한 장 = 한 포인트(제목 7~15자 + 설명 40자 이내) N+1 요약 체크리스트 3줄 마지막 profile-cta(프로필 링크 줄을 짚어 줌).
- 표지 뺀 모든 장에 번호(3/8), 모든 장에 핸들, 대체 텍스트(alt). 번호형 연재는 오른쪽 위 `02 / 10` 진행 표시.
- `cards.json` → `node tools/cards/render.mjs content/<폴더>`(`card-spec.md`).

## 6. 인스타 캡션
- 첫 줄(약 50자, "더 보기" 전)은 숫자가 있는 훅 + `#광고`, 화면 글자와 같은 말(`hook-rules.md` 규칙 4).
- 표준 순서: ① 첫 줄 훅 `#광고` ② 짧은 줄 2~3개로 숫자 이야기(무엇과 무엇, 기준 날짜, 검색어 자연스럽게) ③ 바꾸면 되는 것 한 문장 ④ 번호 목록 3~5줄 ⑤ `💡` 핵심 한 줄 ⑥ `📌` 요청 한 줄 ⑦ 해시태그.
- 요청은 하나만: 기본은 "📌 결제 전에 꺼내 보게 저장해 두세요". 댓글 판정 요청을 시험하는 글은 이 줄을 그것으로 바꿔요(7장).
- 이모지는 💡·📌 두 개만, 각 한 번. 링크는 넣지 않고 프로필 링크로.
- **검색어:** 인스타는 2025년 12월부터 해시태그를 5개까지만 받아요. 노출은 글 속 검색어가 맡아요. 검색어를 넣는 네 자리: 프로필 이름 칸 · 캡션 첫 두 줄 · 화면 글자 · 대체 텍스트. 검색어는 `product-context.md` 1·7장에서, 억지 반복 금지. 해시태그는 끝에 5개 이하, 구체적으로.

## 7. 댓글 (우리 글·남의 글)
**댓글 판정 요청 (시험 중):** "사고 싶은 직구템 이름을 댓글로 남겨 주세요. 같은 모델인지 보고 판정해 드려요."
- 답글은 **운영자가 직접**(자동 답글 안 함). cs-responder가 초안, 숫자는 사이트에 등록된 판정(기준 날짜 같이)이나 그날 매니저가 실물 확인한 값만. 확인 못 했으면 숫자 없이 "같은 모델 찾는 중이에요, 다음 글에서 다룰게요".
- 답글에도 링크 없이 "프로필 링크 → 붙여넣기 판정". 들어온 상품 이름은 product-scout 후보로(등록 가치 3문항), 여러 명이 같은 걸 물으면 다음 소재.

**우리 글의 댓글 답하기:**
- 먼저 분류하고 수를 적어요: 판정 요청 / 직구 고민 / 정보 보탬·반박 / 여러 명이 가질 질문 / 응원 / 스팸.
- 판정 요청은 빠짐없이, 질문엔 답글 안에서 답(DM으로 미루지 않음), 비판은 맞는 부분 먼저 인정(틀린 판정이면 price-checker 확인 → "확인하고 고쳤어요"), 응원은 좋아요 + 한마디, 스팸·악플은 답하지 않고 숨기기.
- **여러 명이 같은 걸 물으면 '댓글에 릴스로 답하기'.** 첫 1시간 답글이 효과가 커요(게시 12:25·17:52 뒤 1시간 안에 한 번).

**남의 인기 직구 글에 댓글 (운영자 직접, 하루 3~5개):**
- 팔로워가 적을 때 가장 싼 노출이에요. 무기는 **확인된 숫자 하나 보태기** 1~3문장. 틀: "같은 모델로 관세까지 넣어 보면 {국내/해외} 쪽이 {확인된 차이}였어요({기준 날짜})".
- 금지: 홍보 문구·링크·"프로필 보세요", 칭찬만, 이모지만, 영상 되풀이, 같은 계정에 매일. 틀린 글엔 친절하게 짧게, 확실할 때만.
- 운영자가 글을 붙여 주면 매니저/cs-responder가 서로 다른 방식 2개를 써 주고 하나 추천. 남의 피드를 대신 훑거나 게시하지 않아요.

## 8. 인스타 프로필·스토리
- 프로필 점검표와 고칠 순서는 `ig-profile.md`. 릴스 조회는 나오는데 팔로우가 안 늘면 프로필부터.
- 스토리: 인스타 글이 올라가면 Actions가 스토리로 한 번 자동 공유(실패하면 운영자가 앱에서 '스토리에 공유'). 질문 스티커는 "사고 싶은 직구템?" 하나, 앞쪽에. 쌓이면 하이라이트 4개(판정 방법·관세 한도·세일 일정·직구각 소개).

## 9. 스레드 (매일 짧게)
- 300~500자: ① 숫자 하나로 시작하는 짧은 정보글 ② 질문형. '오늘의 판정'처럼 매일 같은 틀도 좋아요.
- 링크는 글에 넣지 않고 프로필 링크로(답글 링크는 거의 안 봐요: 10/22·23 첫 글 조회 32·44, 링크 답글 2·0).
- 프로필 링크에 출처 표시: `?utm_source=threads`(인스타는 `utm_source=instagram`).

## 10. 훅 고르기 (표지·릴스 첫 화면·캡션 첫 줄 공통)
규칙은 `hook-rules.md`(1쪽).
1. **social-writer:** 서로 다른 방식으로 훅 **10개**를 표로(번호 | 화면 글자 | 첫마디 | 방식). 방식 5가지(숫자 대비·질문·흔한 실수·반전·직구각 데이터 사례)가 모두 한 번 이상. 답은 숨기고, 화면 글자 = 첫마디, 숫자는 팩트 시트 안에서만. 추천 1개와 이유 한 줄.
2. **marketing-lead:** 가장 궁금증이 큰 1개를 고르고 이유 한 줄을 review.md에(필요하면 `docs/court.md` 배심원 1~7번만으로 짧은 법정). 작가 추천과 다르면 팀장이 고치고 다시 렌더.
3. brief.md엔 훅 문장 대신 맞는 방식 2~3개와 쓰면 안 되는 표현(틀리기 쉬운 숫자)을 적어요.

**참고 틀 (ig-reel 26개 중 직구각에 맞는 것)**
| 공식 | 틀 | 예 |
| --- | --- | --- |
| 비용 고백 | {금액}, {실수 하나}의 값이에요 | 3만 8천 원, 1달러 넘겨서 낸 관세예요 |
| 하지 마세요 | {흔한 행동} 하지 마세요. {대안} 하세요 | 할인율 보고 장바구니 담지 마세요. 최종가를 보세요 |
| 아무도 안 알려 줌 | {불편한 진실}은 아무도 안 알려 줘요 | 알리가 쿠팡보다 비쌀 때가 있다는 건 아무도 안 알려 줘요 |
| 맞대결 | {A} vs {B}, 다 더해 보니 {결과} | 레고 꽃다발 아마존 vs 쿠팡, 관세까지 더해 보니 |
| 숫자 목록+최애 | {N}개 중 {k}번이 제일 의외예요 | 블프 직구 6개 계산해 봤어요. 4번이 제일 의외예요 |
| 반론 | "{흔한 말}" 맞아요. 그런데 {반전} | "직구가 싸죠" 맞아요. 면세 한도 안에서만요 |
| 마감 | {날짜}에 {변화}. 그 전에 {행동} | 11월 27일 블프 전에 손익분기부터 알아 두세요 |
| 허락 | {다들 필요하다는 것} 필요 없어요 | 해외 카드 없어도 돼요 |
| 통계 | {N}개 중 {k}개가 {사실} | 직구각이 판정한 {N}개 중 {k}개는 국내가 더 쌌어요(빌드 결과로 세기) |
| 콕 집기 | {특정 대상}, 이거 보고 사세요 | 블프에 레고 사려는 분, 이 숫자만 기억하세요 |

## 11. 주간 리듬과 회고
- 월: 매니저가 status.md '이번 주 핵심 3개' → trend-scout 소재 3개 → 팀장 주간 계획(블로그 2, 릴스 2, 스레드 매일). 첫 주엔 seo-strategist 월간 노출 점검.
- 화~목: 제작 → 팀장 검수 → 게시 당일 매니저 실물 확인 → 운영자 승인·게시.
- 금: 세일 임박 소재(D-7, D-1) 우선.
- 일(또는 회고일): 숫자 정리 → `product-context.md` '배운 것'에 한 줄.
- **회고 숫자** (`content/_insights/latest.json`): 조회수보다 ① 공유÷도달 ② 팔로우÷도달 ③ 3초 유지율 ④ 팔로워 아닌 사람 도달 비율. 조회는 되는데 팔로우가 없으면 프로필 문제, 조회가 없으면 훅 문제. 글이 적을 땐 "아직 판단 불가"라고 적고, 게시 시각은 맨 마지막에 봐요.
