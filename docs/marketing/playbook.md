# 직구각 마케팅 플레이북 (채널별 형식)

> 인스타그램 에이전트 스킬(Jake Schincariol, MIT)의 ig-carousel·ig-reel·ig-caption·ig-plan·ig-viral 내용을 한국 채널(네이버 블로그·인스타·스레드)과 직구각 규칙에 맞게 옮겼어요. 먼저 `voice.md`를 읽어요.

## 원칙
- **쓰는 건 팀이, 올리는 건 운영자가.** 게시·댓글·팔로우·DM 자동화 도구는 쓰지 않아요(계정 정지 위험).
- **한 콘텐츠 = 한 주제.** 하나의 판정(직구각/애매/국내가 나음)이 결론이에요.
- **하나의 소재 → 세 채널:** 블로그(검색 유입) · 인스타 카드뉴스(저장·공유) · 스레드(대화). 같은 숫자, 채널별 형식.
- 결과물 폴더: `content/YYYY-MM-DD-주제/` → `brief.md`(팀장) · `blog.md` · `instagram.md` · `reel.md`(선택) · `threads.md` · `cards.json` + `cards/*.png` · `review.md`(팀장 검수)

## 광고 표시 (빠지면 안 됨)
- 블로그 맨 위: "이 글은 제휴 활동의 일환으로, 글 속 링크로 구매하면 직구각이 수수료를 받을 수 있어요(구매가는 같아요)."
- 쿠팡 링크나 쿠팡을 언급하며 링크를 걸면: "이 포스팅은 쿠팡 파트너스 활동의 일환으로, 이에 따른 일정액의 수수료를 제공받습니다."
- 인스타: 게시할 때 "유료 광고 포함" 표시를 켜고, 캡션 첫 줄 끝이나 해시태그에 `#광고`. 카드 표지에 "광고 · 제휴 링크 포함".
- 스레드: 글 끝에 `#광고`.
- 블로그·SNS 본문엔 제휴 링크 대신 **직구각 페이지 주소**(https://www.jikgugak.com/p/슬러그, /sale, /search)를 걸어요.

## 네이버 블로그 (검색 유입의 주력)
- **제목:** 검색어를 앞에. "레고 꽃다발 직구 vs 쿠팡, 관세까지 계산해 보니" 형태. 25~35자. 후보 3개.
- **첫 문단(3줄):** 결론 먼저. 판정 + 핵심 숫자 + 기준 날짜.
- **본문 구성:** ① 결론 요약 표(국내가·해외 체감가·차이·판정) ② 왜 이런 결과인지(관세·면세 한도·배송비) ③ 언제 직구각이 되는지(손익분기·세일 일정) ④ 주의할 점 3개 ⑤ 직구각 링크 하나.
- 1,500~2,500자, 소제목 4~6개, 표 1~2개. 검색어는 제목·첫 문단·소제목 1곳에 자연스럽게(억지 반복 금지).
- 이미지 자리는 `[이미지: 설명]`으로 표시(제휴 프로그램 이미지 또는 직구각 카드 이미지만).
- 해시태그(네이버 태그) 10개 이내.

## 인스타 카드뉴스 (저장·공유가 목표)
- **6~10장.** 1080×1350(4:5). 구성:
  1. **표지:** 6~12자 훅 + 한 줄 약속. 썸네일에서도 읽혀야 해요. 표지가 결과의 80%.
  2. **문제 제기:** 왜 중요한지 한 문장. 이 장도 두 번째 표지 역할(인스타가 2장부터 다시 보여 줄 때가 있어요).
  3~N. **한 장 = 한 포인트.** 제목 7~15자 + 설명 40자 이내. 넘치면 두 장으로.
  N+1. **요약(정리) 장:** 전체를 목록으로. 캡처해서 보내는 장이에요.
  마지막. **CTA 한 개:** 저장 / 프로필 링크 / 댓글 키워드 중 하나.
- 모든 장에 번호(3/8)와 핸들. 대체 텍스트(alt) 표지 1줄 이상.
- 카드 문구는 `cards.json`으로 → `node tools/cards/render.mjs content/<폴더>` 로 이미지 생성(`card-spec.md`).

## 인스타 캡션
- 카드뉴스는 캡션이 2차 훅이에요: **첫 줄(약 50자, "더 보기" 전에 보이는 부분)** 에 숫자가 있는 훅.
- 본문: 짧은 문단 2~5개, 사람들이 검색할 말("레고 꽃다발 직구", "레고 관세")을 문장 속에.
- 요청은 하나. 링크는 캡션에 넣지 않아요("프로필 링크").
- 해시태그 **5개 이하**, 구체적으로(#레고꽃다발 #해외직구 #관부가세 …). #광고 포함.

## 릴스 대본 (선택, 얼굴 없이 화면 녹화 + 자막 형식)
- 15~35초. 구조: 0~2초 훅 → 2~7초 이유 → 본문(한 박자 = 한 장면) → 마지막 3초 결과 + 요청 → 첫 단어로 되돌아오는 마무리.
- 훅 3개를 서로 다른 공식으로 쓰고, 팀장이 점수(숫자 구체성·호기심·10자 이내 자막 가능 여부, 각 0~10)로 고름.
- 화면 자막은 따로, 한 장면 12자 이내. 아래쪽(캡션 가리는 곳)엔 넣지 않기.

## 한국어 훅 공식 (ig-reel 26개 중 직구각에 맞는 것)
| 공식 | 틀 | 예 |
| --- | --- | --- |
| 비용 고백 | {금액}, {실수 하나}의 값이에요 | ₩38,000, $1 넘겨서 낸 관세예요 |
| 하지 마세요 | {흔한 행동} 하지 마세요. {대안} 하세요 | 할인율 보고 장바구니 담지 마세요. 최종가를 보세요 |
| 아무도 안 알려 줌 | {불편한 진실}은 아무도 안 알려 줘요 | 알리가 쿠팡보다 비쌀 때가 있다는 건 아무도 안 알려 줘요 |
| 맞대결 | {A} vs {B}, 다 더해 보니 {결과} | 레고 꽃다발 아마존 vs 쿠팡, 관세까지 더해 보니 |
| 숫자 목록+최애 | {N}개 중 {k}번이 제일 의외예요 | 블프 직구 6개 계산해 봤어요. 4번이 제일 의외예요 |
| 반론 | "{흔한 말}" 맞아요. 그런데 {반전} | "직구가 싸죠" 맞아요. 면세 한도 안에서만요 |
| 마감 | {날짜}에 {변화}. 그 전에 {행동} | 11월 27일 블프 전에 손익분기부터 알아 두세요 |
| 허락 | {다들 필요하다는 것} 필요 없어요 | 해외 카드 없어도 돼요 |
| 통계 | {N}개 중 {k}개가 {사실} | 직구각이 판정한 {N}개 중 {k}개는 국내가 더 쌌어요(숫자는 빌드 결과로 세기) |
| 콕 집기 | {특정 대상}, 이거 보고 사세요 | 블프에 레고 사려는 분, 이 숫자만 기억하세요 |

## 스레드
- 300~500자 글 2개: ① 숫자 하나로 시작하는 짧은 정보글 ② 질문형(“여러분은 직구 몇 달러부터 고민하세요?”).
- 링크는 본문 끝에 하나(jikgugak.com 페이지). `#광고`.

## 주간 루틴 (계정이 생기면)
- 월: trend-scout가 소재 3개 + 잘 되는 구조 보고 → 팀장이 주간 계획(블로그 2, 카드뉴스 2, 스레드 3)
- 화~목: 작가·디자이너 제작 → 팀장 검수 → 운영자 게시
- 금: 세일 임박 소재(D-7, D-1) 우선
- 일: (데이터가 생기면) 지난주 반응 정리 → 다음 주 반영
