# 마케팅 팀장 검수 체크리스트

결과는 `content/<폴더>/review.md`에: 항목별 통과/수정함/운영자 확인 필요, 고친 내용 요약, 최종 판정(게시 가능 / 수정 후 재검수).

## 1. 숫자 (하나라도 틀리면 게시 불가)
- [ ] 모든 가격·체감가·손익분기·차이·퍼센트를 `npm run build` 출력과 `dist/p/<슬러그>.html`에서 다시 찾아 대조했다
- [ ] 국내가에 배송비가 들어갔는지 사이트와 같다(예: "쿠팡 ₩60,730 + 배송비 ₩10,000")
- [ ] 기준 날짜를 적었다(상품 checkedAt, 환율 날짜)
- [ ] 세일 날짜는 data/events.json과 같고, '예상'인 건 "예상"이라고 썼다
- [ ] 계산 근거(면세 한도 $150/$200, 관세율, 환율)가 CLAUDE.md 판정 규칙과 맞다

- [ ] 글에 나온 상품의 '살 수 있는 상태'(아마존 한국 배송 가능, 품절 아님)를 팩트 시트에 확인 날짜와 함께 적었고, 확인 못 한 건 "매니저 실물 확인 필요"로 review.md에 남겼다

## 2. 규칙 (어기면 제휴 계정 정지)
- [ ] **아마존 가격 숫자 없음** (손익분기 "아마존가 $○○ 이하면"만)
- [ ] 광고 표시: 블로그 맨 위 문구, 쿠팡 언급+링크 시 쿠팡 파트너스 문구, 인스타 #광고·표지 표시, 스레드 #광고
- [ ] 본문 링크는 jikgugak.com 주소만(제휴 링크 직접 노출 X). 우리가 제휴 링크를 연 적 없음
- [ ] 브랜드 로고·남의 사진 없음. 이미지는 직구각 카드 또는 제휴 프로그램 제공 이미지
- [ ] 상표는 상품명 표기로만("레고 보태니컬 플라워 부케 10280"), 공식 관계처럼 보이는 표현 없음
- [ ] 효능·건강 효과 주장 없음(영양제), "최저가 보장" 같은 단정 없음

## 3. 정직함
- [ ] 국내가 나은 경우를 숨기지 않았다
- [ ] 체험담·후기·별점을 지어내지 않았다
- [ ] "무조건", "역대급", "인생템" 등 voice.md 금지어 없음

## 4. 사람 말투 (ig-human을 한국어로)
자동으로 고칠 것:
- [ ] 줄표(—), 말줄임표 문자(…), 둥근 따옴표 → 쉼표·"..."·곧은 따옴표
- [ ] 보이지 않는 문자(제로폭 공백 등) 제거: `grep -nP '[\x{200B}-\x{200F}\x{2060}\x{FEFF}\x{00AD}]'`
AI 티 나는 말(빼거나 평범한 말로):
- "~에 대해 알아보겠습니다", "~를 소개해 드릴게요", "결론적으로", "요약하자면", "다양한", "효과적인", "혁신적인", "필수템", "놓치지 마세요", "주목해 주세요", "완벽 가이드", "총정리", "~의 세계", "여러분의 ~을 한 단계 업그레이드", "꿀팁 대방출", "이것만 알면 끝"
구조 신호(손으로 다시 쓰기):
- "단순히 A가 아니라 B예요" / "A뿐만 아니라 B도" 반복
- 세 개씩 나열하는 습관(매 문단 3단 나열)
- "결과는?" 같은 한 단어 질문 줄
- 이모지 글머리표 목록, 해시태그 벽(인스타 6개 이상)
- 문장 길이가 다 비슷함 → 짧은 문장과 긴 문장을 섞기

## 5. 채널 형식 (playbook.md)
- [ ] 블로그: 제목에 검색어 앞쪽, 첫 문단 결론, 표, 링크 하나
- [ ] 카드: 표지에 상품 사진(제휴 이미지) 있음, 6~10장, 표지 12자 이내 훅, 한 장 한 포인트, 요약 장, CTA 하나, 번호(표지 제외)·핸들, 렌더 경고 없음, 이미지 직접 열어 확인
- [ ] 캡션: 첫 줄 훅에 숫자, 요청 하나, 링크 없음, 해시태그 5개 이하
- [ ] 스레드: 2개, 각 500자 이내, #광고
