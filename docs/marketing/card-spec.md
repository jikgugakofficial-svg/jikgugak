# 카드뉴스 이미지 규격 (card-designer)

- 크기 1080×1350(4:5) PNG. 글자는 32px 이상(폰에서 1/3 크기로 보임). 바깥 120px 안쪽에만 중요한 글자.
- 색: 직구각 빨강 #D23A10 · 노랑 #FFE14D · 잉크 #16181D · 판정색(직구각 초록 #0E7C4A, 애매 #8A5A00, 국내가 나음 파랑 #2F5FD0).
- **표지엔 상품 사진이 기본이에요.** 사진은 제휴 프로그램 이미지(쿠팡 파트너스 썸네일·알리 제휴 API 이미지)만 써요. 매니저가 브라우저로 받아 `content/<폴더>/img/<이름>.jpg`에 넣어 주고(흰 여백은 잘라 둠), 카드에는 `"image": "img/<이름>.jpg"`로 넣어요. 표지(cover)·포인트(point) 장에 쓸 수 있어요. 브랜드 로고 따로 붙이기·남의 사진은 금지.
- 제작: `content/<폴더>/cards.json` 작성 → `node tools/cards/render.mjs content/<폴더>` → `cards/01.png …`, `cards/deck.html`.
- 렌더가 "⚠ 글자가 넘칠 수 있는 장"을 알려 주면 문구를 줄이고 다시 렌더. 마지막엔 PNG를 Read로 직접 열어 눈으로 확인.

## cards.json
```json
{
  "handle": "@jikgugak",
  "ad": true,
  "alt": "표지 대체 텍스트",
  "slides": [
    { "type": "cover", "kicker": "작은 윗글", "title": "6~12자 훅\n두 줄까지", "sub": "한 줄 약속", "badge": "선택: 노란 배지" },
    { "type": "point", "label": "선택: 노란 라벨", "title": "제목 7~15자", "body": "설명 40자 이내", "big": "선택: 큰 숫자" },
    { "type": "compare", "title": "비교 제목", "rows": [["쿠팡", "₩71,570", "dim"], ["아마존가 이하면 직구각", "$43", "hi"]], "note": "작은 주석" },
    { "type": "verdict", "verdict": "good|meh|bad|wait", "word": "선택: 판정 단어 바꾸기", "line": "판정 아래 한 줄", "title": "제목", "body": "설명" },
    { "type": "shot", "label": "선택: 노란 라벨", "title": "제목", "image": "img/03-product.png", "body": "선택: 한 줄" },
    { "type": "recap", "title": "정리", "items": ["한 줄", "한 줄", "한 줄"] },
    { "type": "cta", "title": "저장해 두세요", "body": "한 줄", "button": "프로필 링크 → jikgugak.com" }
  ]
}
```
- rows 세 번째 값: `hi`(빨강 강조) · `good`(초록) · `dim`(흐리게) · 비우면 회색.
- `big`(큰 숫자)에는 달러 금액을 넣지 않아요. 아마존 가격처럼 읽혀요. %·원화·면세 한도만 써요.
- 줄바꿈은 `\n`. 한 장의 글자 수가 많으면 두 장으로 나눠요.
- `shot`: 사이트 화면 캡처를 크게 넣는 장. 캡처는 매니저가 모바일 폭(390px, 2배 해상도)으로 기능 하나만 잘라서 `img/`에 넣어 줘요.
- 시리즈: cards.json 맨 위에 `"series": "직구각 사용법 1/5"`를 넣으면 표지 오른쪽 위에 표시돼요. 표지엔 "넘겨서 확인 →"가 자동으로 붙어요(끄려면 `"swipe": false`).
- 표지 대비형: cover에 `"vs": [["쿠팡", "₩59,900"], ["직구 최종가", "₩33,400"]]`를 넣으면 두 값을 나란히 보여 줘요(마지막 칸이 노란 강조). 아마존 가격은 넣지 않아요.
- 표지 원칙(content/_research/2026-10-22-cardnews-hooks.md): 구체 숫자 하나, 결론은 2장으로 미루기, 통념 반박·vs 대비, 12자 이내 + 한 줄 부제, 2장은 단독으로도 읽히게, 시리즈는 틀·강조색 고정.
- `shot` 캡처는 칸 너비에 맞춰 위쪽부터 채우고 아래는 잘려요. 중요한 내용이 캡처 위쪽 약 340px(모바일 기준)에 오게 잘라 주세요.
