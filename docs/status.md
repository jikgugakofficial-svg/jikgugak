- 네이버 게시 키트: `python3 tools/publish/naver/kit.py content/<폴더> content/<폴더>/naver/naver-kit.html "<이름>"`(blog.md는 `## 제목 후보`·`추천: N번`·`## 본문`·`## 네이버 태그`, 이미지 `[이미지: img/파일, 설명]` + `naver/map.json`). 아티팩트로 올리고 사진 zip 전달.
